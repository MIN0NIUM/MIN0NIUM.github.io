PDG Rock Exporter

PDGについて教える講習会のため作成しました。コケの生えた岩を生成し、頂点カラーによりコケの厚さで頂点変形、マテリアルもブレンドしています。

  • Houdini

Output comp images

レイヤカンプの状態ごとに画像を書き出します。2Dキャラクターパーツの重なり具合などを確認しながら出力できます。

  • JavaScript
  • Photoshop

Texture Exporter for Photoshop

Photoshop上で特定のレイヤテンプレートを作成、テンプレートに合わせてテクスチャを出力します。1チャンネル成分はRGBに格納可能、任意の命名規則で出力できます。

  • JavaScript
  • Photoshop

Texture Exporter for Blender

Blenderの各種マテリアルをUVにベイク、テンプレートに合わせてテクスチャを出力します。1チャンネル成分はRGBに格納可能、任意の命名規則で出力できます。

  • Blender
  • Python

Unreal Asset Prep for Blender

Unreal向けStatic Meshアセットを出力します。

  • Blender
  • Python

Cycles Pass Exporter

各種パスごとに任意の画像フォーマットで出力

  • Blender
  • Python
